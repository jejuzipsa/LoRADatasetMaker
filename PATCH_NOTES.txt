0008 - SFace identity embedding
- 기존 gray + HSV 임시 descriptor 동일인물 판정을 SFace 얼굴 임베딩으로 교체
- OpenCV Zoo face_recognition_sface_2021dec.onnx 자동 다운로드 및 SHA256 검증 추가
- YuNet 5-point landmark로 얼굴 정렬 후 SFace feature 추출
- OpenCV Zoo 기준 cosine threshold 0.363을 REVIEW 하한으로 적용
- cosine 0.45 이상은 동일인물 강한 후보, 0.363~0.45는 REVIEW, 0.363 미만은 REJECTED
- 여러 얼굴이 있는 이미지에서는 기준 인물과 SFace similarity가 가장 높은 얼굴을 선택
- 선택된 얼굴 기준으로 face box / Head Crop을 다시 맞춤
- 동일인물 판정을 QThread 백그라운드 작업으로 전환하고 진행률 표시
- 자동 분석 시 YuNet/SFace 필수 모델을 미리 확인하여 기준 인물 지정 시 다운로드 대기 최소화
- 모델 출처와 Apache 2.0 라이선스 정보를 models/README.md에 기록
- 패키지 버전 0.0.8

0012 - Relax automatic quality demotion
- 정상적인 얼굴/머리 크롭은 기본적으로 ACCEPTED를 유지하도록 품질 판정 정책 완화
- crop_touches_edge는 REVIEW 강등 조건에서 제거하고 진단 사유/소폭 점수 감점만 유지
- YuNet detection confidence 0.94 미만 자동 REVIEW 조건 제거, 0.90 미만은 진단 정보만 기록
- 얼굴 크기 자동 강등 기준 완화: 48px 미만 REJECTED, 48~71px REVIEW, 72~95px는 경고만 기록
- 블러 기준 완화: 12 미만 REJECTED, 12~27 REVIEW, 28~44는 경고만 기록
- 노출 기준 완화: 극단 노출만 REJECTED, 명확한 저/과노출만 REVIEW
- quality_score 80 미만이라는 이유만으로 REVIEW 처리하던 규칙 제거
- Vision 후보에서 crop_touches_edge 단독 조건 제거
- Vision 품질점수 후보 기준을 88 미만에서 70 미만으로 완화
- 패키지 버전 0.0.12
