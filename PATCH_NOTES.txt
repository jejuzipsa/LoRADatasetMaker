LoRADatasetMaker PATCH NOTES

0001 - Project scaffold
- 프로젝트 목적과 1차 범위 정의
- 자동 판정은 삭제가 아닌 추천 상태로 설계
- ACCEPTED / REVIEW / REJECTED 3상태 정의
- 제외/보류 이미지도 프리뷰 및 결과에 전부 보존
- 사용자 override 및 판정 로그 설계
- 얼굴 검출 / 동일인물 / 품질 / 중복 / Head Pose / Crop / Caption / Export 파이프라인 정의
- 기본 Head Crop 1024x1024 방향 설정
- Qwen/WAN LoRA Trainer는 후속 단계로 분리

- Windows 데스크톱용 PySide6 기본 UI 추가

- 원본을 수정하지 않는 ImageRecord 상태 모델 추가
- ACCEPTED / REVIEW / REJECTED 최종 상태 수동 변경 지원
- 자동 상태와 사용자 override를 분리 저장할 구조 구현
- 썸네일 그리드, 원본 상세 프리뷰, Caption 수정 UI 추가
- 전체/채택/보류/제외 카운트 표시
- 얼굴 검출/동일인물/품질 AI 단계는 아직 연결하지 않고 분석 버튼 비활성화
