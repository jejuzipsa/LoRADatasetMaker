LoRADatasetMaker PATCH NOTES

0001 - Project scaffold
- 프로젝트 목적과 1차 범위 정의

- 제외/보류 이미지도 프리뷰 및 결과에 전부 보존
- 사용자 override 및 판정 로그 설계
- 얼굴 검출 / 동일인물 / 품질 / 중복 / Head Pose / Crop / Caption / Export 파이프라인 정의

- Qwen/WAN LoRA Trainer는 후속 단계로 분리

- 자동 상태와 사용자 override를 분리 저장할 구조 구현
- 썸네일 그리드, 원본 상세 프리뷰, Caption 수정 UI 추가
- 전체/채택/보류/제외 카운트 표시
- 패키지 버전 0.0.2

- frontal/profile 조합으로 front, left_profile, right_profile 기초 방향 태그 추가

- 얼굴이 여러 개 검출되면 REVIEW 처리 및 multiple_faces_detected 사유 기록
- Trigger token 기반 기본 caption 자동 생성
- 원본 + 크롭 프리뷰 동시 표시
- accepted 상태 이미지를 1024 PNG + TXT로 export 하는 기초 기능 추가
- logs/decisions.json 감사 로그 출력 추가
- 패키지 버전 0.0.3

0007 - YuNet face detector / reliable crop
- Haar Cascade 기반 얼굴 검출을 YuNet FaceDetectorYN으로 교체
- 배경/문양 등을 얼굴로 오인해 엉뚱한 위치를 Head Crop하던 문제 개선
- 첫 자동 분석 시 face_detection_yunet_2023mar.onnx를 app-local models 폴더에 자동 다운로드
- YuNet 모델 SHA256 검증 및 손상 파일 자동 재다운로드
- 이후 실행에서는 로컬 모델을 재사용하여 오프라인 분석 가능
- confidence 0.90 기준 적용
- 원본 프리뷰에 실제 검출 얼굴 박스와 confidence 표시
- decisions.json에 detection_confidence 기록
- YuNet 5-point landmark 기반 기초 좌/우 방향 태그 계산
- 패키지 버전 0.0.7

0008 - SFace identity embedding
- 기존 gray + HSV 임시 descriptor 동일인물 판정을 SFace 얼굴 임베딩으로 교체
- OpenCV Zoo face_recognition_sface_2021dec.onnx 자동 다운로드 및 SHA256 검증 추가
- YuNet 5-point landmark로 얼굴 정렬 후 SFace feature 추출
- OpenCV Zoo 기준 cosine threshold 0.363을 REVIEW 하한으로 적용
- cosine 0.45 이상은 동일인물 강한 후보, 0.363~0.45는 REVIEW, 0.363 미만은 REJECTED
- 여러 얼굴이 있는 이미지에서는 기준 인물과 SFace similarity가 가장 높은 얼굴을 선택
- 선택된 얼굴 기준으로 face box / Head Crop을 다시 맞춤
- 동일인물 판정을 QThread 백그라운드 작업으로 전환하고 진행률 표시
- 자동 분석 시 YuNet/SFace 필수 모델을 미리 확인하여 기준 인물 지정 시 다운로드 대기 최소화
- 모델 출처와 Apache 2.0 라이선스 정보를 models/README.md에 기록
- 패키지 버전 0.0.8
