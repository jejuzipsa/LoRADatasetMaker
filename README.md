# LoRADatasetMaker

Windows용 로컬 LoRA 학습 데이터셋 전처리/검수 도구.

## 1차 목표
사진을 대량 투입하면 자동으로 동일 인물 후보를 분류하고, Head/Portrait 학습용 크롭·품질 검사·중복 판정·얼굴 방향 분석·캡션 생성을 수행한 뒤, 사용자가 모든 채택/제외/보류 결과를 프리뷰에서 최종 검수하여 LoRA 학습용 데이터셋으로 Export한다.

## 핵심 원칙
- 자동 판정은 삭제가 아니라 **추천 상태**다.
- 채택/제외/보류 이미지를 모두 보존하고 UI에서 모두 확인할 수 있어야 한다.
- 사용자는 자동 제외된 이미지를 다시 채택할 수 있어야 한다.
- 원본 파일은 수정하거나 삭제하지 않는다.
- 최종 학습 폴더와 감사/검수 로그를 분리한다.
- v0.x에서는 LoRA 학습 자체를 포함하지 않고 Dataset Maker에 집중한다.
- 이후 Qwen Image / WAN용 Trainer를 별도 모듈로 연결한다.

## 목표 사용 흐름
1. 사진 폴더 선택
2. 기준 인물 얼굴 선택
3. 자동 분석
4. 전체 결과 프리뷰
5. 채택/제외/보류 수동 보정
6. 캡션/방향 태그 수정
7. Dataset Export
8. 외부 LoRA Trainer에서 학습

자세한 설계는 `docs/SPEC.md`, `docs/PIPELINE.md` 참고.
